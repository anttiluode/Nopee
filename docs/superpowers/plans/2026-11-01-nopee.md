# Nopee Implementation Plan

> Execute inline using superpowers:executing-plans; verify scientific invariants
> with test-driven-development and request a final independent code review.

**Goal:** Run and compare a tiny frame predictor with a spatial/E-I memory adapter.
**Architecture:** Shared frozen CNN base, separately trained adapter variants,
causal rollouts, reproducible synthetic data, Gradio UI and CLI.
**Tech stack:** Python 3.10+, PyTorch, NumPy, Pillow, imageio, Gradio 5.49.1.
**Spec:** docs/design.md

## Global constraints

- 32x32 grayscale; no biological constants or speedup claims without evidence.
- CPU Space works without downloading pretrained models; CUDA optional locally.
- No future ground-truth frames may influence a forecast.
- Same base weights, training data, initial adapter weights, evaluation seeds.
- No training on uploads; bounded video decoding and temporary outputs.

## Review focus

- Forecast leakage: altered future truth must not change a prediction.
- Reset and frame clocks: memory must not cross requests or tick per refinement.
- CPU/GPU devices and package launch: test app/API and CLI in a clean process.
- Missing/malformed checkpoints and short/bad uploads: actionable errors.
- Invalid budgets and metrics that reward static output: test range and truth-relative motion.
